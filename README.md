# Personal Portfolio Website

A responsive personal portfolio website built with HTML5, CSS3, and JavaScript to showcase my background, technical skills, projects, achievements, and contact information.

## Sections Included
- **Home:** Name, title, short tagline, and quick navigation buttons.
- **About Me:** Personal introduction and educational background.
- **Skills:** Categorized technical and programming skills.
- **Projects:** Highlights of completed web development and programming projects.
- **Achievements:** Relevant certificates, seminars, and academic awards.
- **Contact Me:** Email, social links, and an interactive message form.

## Technologies Used
- HTML5
- CSS3 (Flexbox, CSS Grid, Media Queries)
- Vanilla JavaScript
